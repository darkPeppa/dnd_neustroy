# neustroy

Игровой стол для D&D, SRD 2014/2024 и домашних правил. Веб работает на React и TypeScript. Android, iOS и настольный клиент работают на Kotlin и Compose. Клиенты используют общий API. [Состояние функций и проверок](REPORT.md) и [сценарии тестирования](TEST_CASES.md).

## Установить Android

1. Откройте [Native apps в GitHub Actions](https://github.com/darkPeppa/dnd_neustroy/actions/workflows/mobile.yml). Выберите сборку ветки `main` и скачайте `neustroy-android-apk` из **Artifacts**. Для скачивания артефактов GitHub может попросить войти.
2. Распакуйте ZIP и откройте `neustroy-android.apk` на телефоне с Android 8 или новее. Если устройство спросит, разрешите установку из того приложения, которым открыли APK. Сборка подписана ключом разработки.
3. Выберите **Начать локально** для работы на телефоне. Для совместной игры укажите адрес запущенного сервера, нажмите **Подключиться**, затем **Регистрация** или **Email и пароль**. Пароль содержит минимум 12 символов.

`Native apps` также собирает macOS DMG, Linux DEB, переносимый Windows ZIP и архив iOS. На Windows распакуйте всю папку и откройте `neustroy.exe`. Архив iOS нужно подписать Apple Developer в Xcode перед установкой.

## Запустить сервер с аккаунтами

Исходники и Docker Compose:

```sh
docker compose up -d --build
```

Или загрузите `neustroy-server-image` из [Check neustroy](https://github.com/darkPeppa/dnd_neustroy/actions/workflows/check.yml), распакуйте ZIP и запустите образ на Linux x86-64:

```sh
docker load -i neustroy-server-linux-amd64.tar.gz
docker run -d --name neustroy --restart unless-stopped -p 8787:8787 -v neustroy-data:/data neustroy-api:local
```

На компьютере откройте http://127.0.0.1:8787. Для телефона в той же сети используйте `http://IP_КОМПЬЮТЕРА:8787`. Укажите этот адрес в приложении. Для работы через интернет настройте обратный прокси с HTTPS, оставьте порт 8787 доступным прокси и задайте внешний адрес через `PUBLIC_APP_URL` при запуске. Без Docker:

```sh
npm ci
npm run build
npm run server
```

Для установки зависимостей и запуска используется Node.js 24. Если запускаете через Node.js 20, скрипт переключится на установленный Node.js 24 или попытается запустить его через npm. Для LAN без регистрации используется `npm run lan`. В браузере автономный режим открывается по `/local`.

Первый аккаунт, зарегистрированный напрямую с компьютера при запуске через Node, получает роль владельца. При запуске в Docker зарегистрируйтесь, затем в настройках введите одноразовый ключ из `docker compose exec -T api cat /data/admin-setup.txt` (для `docker run` используйте `docker exec neustroy cat /data/admin-setup.txt`). Берегите ключ настройки. Сервер хранит базу, вложения и ключ шифрования в томе `/data`, а при запуске из исходников в `.local/accounts`. Для полной копии остановите сервер и скопируйте весь том или папку.

## Подключить Telegram и почту

1. Создайте бота у [BotFather](https://t.me/BotFather). Под аккаунтом владельца откройте **Настройки → Подключения** и вставьте токен. Сервер проверит его и определит имя бота. Отдельный Node/Docker-сервер получает сообщения исходящим опросом. Сервер должен быть включён и иметь доступ к Telegram. Используйте один экземпляр сервера для этого бота. Если раньше бот использовал webhook, удалите его в старой интеграции перед включением опроса.
2. Игрок входит через email, затем выбирает **Настройки → Устройство и доступ → Telegram → Создать ссылку привязки** и нажимает **Start** у бота. Команда `/help` показывает команды. `/games` и `/use` выбирают кампанию, `/note` и `/shared` ведут журнал, `/chat` пишет в общий чат, `/dice` бросает кубы, `/sessions` и `/materials` показывают доступные встречи и материалы. Для `/summary` настройте серверную модель.
3. Для повторного входа выполните у привязанного бота `/login`, затем в приложении выберите **Код из Telegram**. Код действует 5 минут и используется один раз. Отвязка отзываёт выданные ботом сеансы. Бот работает в личном чате и проверяет права пользователя в кампании.
4. Для восстановления пароля сохраните ключ Resend, подтверждённый адрес отправителя и внешний HTTPS-адрес. Google Apps Script для Таблиц, Календаря и доставки заявок находится в `scripts/google-apps-script.gs`. В настройках укажите URL и секрет. Для автоматических Telegram-уведомлений мастеру задайте Chat ID.

## Помощники и сборка

Для модели на своём сервере запустите `docker compose --profile models up -d` и `docker compose exec ollama ollama pull qwen3:4b`. В настройках модели укажите `http://ollama:11434/v1` и `qwen3:4b`. Для Groq, OpenRouter, DeepSeek и OpenAI используйте свой ключ в помощнике. Квоты зависят от провайдера. Агент в ChatGPT использует отдельно подключённый MCP `/mcp` и профиль ChatGPT. В режиме API собственная подписка на чат не заменяет ключ провайдера.

Локальная разработка:

```sh
npm run build
npm test
npm run test:local
node tests/local-runtime-smoke.mjs --accounts
npm run apk
npm run mobile:desktop
npm run mobile:ios
```

Для Android нужны JDK 21 и Android SDK Platform 36, Build Tools 35.0.0. Gradle Wrapper входит в проект. APK появляется в `dist/mobile/neustroy-android.apk`. Для iOS нужны macOS, Xcode, XcodeGen и JDK 21; архив получается в `dist/mobile/neustroy-unsigned.xcarchive`. Настольная команда по умолчанию собирает JAR; CI упаковывает приложение для каждой ОС.

В Site используется внешняя приватная авторизация ChatGPT. Для прямого входа игроков из приложения используйте отдельный сервер. Домен `neustroy.ru` ждёт настройки DNS. Открытые правила и лицензии перечислены в [data/SOURCES.md](data/SOURCES.md).
