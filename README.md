# neustroy

Мобильное приложение и сайт мастера D&D. Синий октаэдр к8, восемь букв **n e u s t r o y**, геометрические развёртки и сменные мотивы: гирлянда, зубцы, зимний лес. Основа для личного бренда преподавателя физики и мастера историй.

**TypeScript · React · Capacitor 8 · SQLite/D1 · R2**. Общая логика для веба, Android, iOS, офлайн-режима и сервера локальной сети. Базовый интерфейс на русском; открытые тексты SRD сохранены на языке оригинала (EN).

## Быстрый запуск без аккаунта

Приложение использует Node.js **24 LTS** (для встроенного `node:sqlite`). Команды проекта автоматически находят установленную совместимую версию, даже если в терминале выбран Node 20. Поддерживаются PATH, комплект Codex и распространённые менеджеры версий. Системный Node при этом не меняется. Если подходящей версии нет, запуск покажет инструкцию по установке. Версия также закреплена в `.nvmrc` и `.node-version`.

```sh
npm ci
npm run build
npm run local
```

Если Node.js 24 установлен в другом месте, можно явно указать путь:

```sh
NEUSTROY_NODE=/полный/путь/к/node npm run local
```

Открыть `http://127.0.0.1:8787`. Локальный мастер определяется по loopback-подключению; регистрация и ChatGPT не нужны. Данные находятся в `.local/neustroy.sqlite`, вложения — в `.local/files/`. Эти файлы игнорируются Git.

Для общей партии в одной сети:

```sh
npm run lan
```

Сервер покажет адрес вида `http://192.168.x.x:8787`. Остальные игроки открывают его в браузере. Каждому устройству выдаётся отдельная подписанная cookie; имя меняется в настройках. Мастер с хост-компьютера создаёт кампанию, передаёт код приглашения и раскрывает материалы. Обычные игроки не получают права мастера. Этот режим рассчитан на доверенную локальную сеть, без проброса порта в интернет.

Веб-сайт также предлагает кнопку **«Локально, без аккаунта»** (`/local`). В этом режиме SQLite и вложения хранятся в IndexedDB конкретного браузера. После первого полного открытия статические файлы, WASM и библиотека правил кешируются Service Worker. Полностью автономный первый запуск — через локальную установку; первичная загрузка опубликованного сайта требует сети. Очистка данных браузера удаляет локальную базу: экспортируйте важные листы. Перенос в облако выполняется вручную через JSON-экспорт и импорт; автоматической отправки локальных данных нет.

## Вход без ChatGPT

На облачном сайте доступны **email + пароль** и дополнительный вход через ChatGPT. Пароль — от 12 символов, PBKDF2-HMAC-SHA256 со случайной солью, в базе хранится только хеш. Веб-сессии — HttpOnly/SameSite cookie, в HTTPS Secure; сервер хранит хеши токенов. Есть ограничение частоты попыток и отзыв текущей сессии при выходе. Для native-клиента возвращается Bearer-токен с ограниченным сроком.

Email пока не подтверждается письмом. Восстановление пароля по почте не подключено — интерфейс предупреждает об этом. Независимый аккаунт и ChatGPT-профиль не объединяются автоматически по email. Заголовки `oai-authenticated-user-*` доверяются только внутри Sites; самостоятельный локальный сервер удаляет входящие заголовки личности и формирует их сам. Не разворачивайте голый Worker на другом публичном proxy без проверки этой границы.

На опубликованном сервере используются `AUTH_ENABLED=true` и секрет `ADMIN_SETUP_SECRET`. Первый зарегистрировавшийся не становится администратором. Владелец входит своим аккаунтом и один раз вводит ключ в «Настройки → Устройства и доступ → Первичная настройка мастера». Ключ текущего развёртывания сохранён только в игнорируемом файле `.local/admin-setup.txt`, не в исходниках. После успешной настройки ключ больше нельзя использовать для другого аккаунта.

## Листы и редакции правил

- Отдельные профили **5e 2014 / SRD 5.1**, **5e 2024 / SRD 5.2.1**, **свои правила / другая редакция**.
- Все 12 базовых классов и доступные в SRD подклассы, уровни 1–20. Отдельные списки способностей и заклинаний по редакции, классу и уровню.
- Пошаговое заполнение имени, вида, предыстории, класса, подкласса и характеристик; стандартный массив; навыки, компетентность, инвентарь, черты и заметки. Числа и бонусы происхождения вносятся явно.
- Автоматические модификаторы, мастерство, базовые спасброски, навыки, HP по средней кости, КД, инициатива. Полные, половинные и договорные ячейки, включая отличие паладина/следопыта на 1-м уровне в 2024. Отдельные версии лечебных заклинаний.
- Броски d4–d100, формулы, преимущество/помеха, атаки, доступный по данным урон/лечение, ячейки, критические попадания и рост заговоров. Сложные многоэтапные эффекты, концентрация, условия, количество подготовленных заклинаний и особые правила остаются под контролем мастера.
- **5 оформлений листа**: стандартное, синий neustroy, гирлянда, хоррор, зимний лес. Тема сохраняется с листом, применяется к печати. Кнопка «Печать» позволяет сохранить PDF через диалог браузера.
- JSON-импорт/экспорт, защита от перезаписи новой версии листа другим устройством. Старые листы автоматически получают профиль 2014 и стандартное оформление.
- Редактор авторского пакета во фронтенде и JSON-импорт: заклинания и способности с уровнем доступности. Свой класс может задать кость HP, основную характеристику и тип ячеек. Пакеты добавляются к конкретному листу; это не полная автоматизация старых редакций или произвольных систем.

## Полная открытая библиотека

**3206 структурированных записей** двух изданий и **767 страниц** полного текста официальных SRD. Классы, подклассы, виды, предыстории, черты, все представленные в открытых источниках заклинания, оружие, доспехи, снаряжение, магические предметы и существа. Условия и общие правила доступны в полном тексте.

Каталог ищется и фильтруется в приложении, оригинальные PDF доступны по ссылкам. Структурированные данные Open5e `srd-2024` помечены самим источником как SRD 5.2; точный текст 5.2.1 отдельно включён полностью. Для спорных мест и табличной вёрстки используйте официальный PDF. Закрытые книги D&D в библиотеку не входят. Подробные источники и обязательная атрибуция — [data/SOURCES.md](data/SOURCES.md).

Снимки лежат в `data/vendored/*.json.gz`. Обычная сборка распаковывает их локально без обращения к внешнему API. `scripts/sync-rules.mjs` обновляет структурированный каталог только при явном запуске. После обновления исходных официальных текстов выполните `node scripts/pack-rules.mjs` и проверьте изменённые правила.

## Кампании и сайт мастера

Сохраняются кампании, приглашения, голосования за время, подтверждение и отмена встреч, открытые игры с ограничением мест, ICS с напоминанием. База атомарно запрещает пересечение подтверждённых встреч и броней одного мастера. Улики, переписки и вложения до 5 МБ раскрываются всем или выбранным игрокам; просмотр и скачивание проверяют доступ на сервере.

Конструктор приключения включает формат, 1–6 игроков, возраст, 2–8 часов, опыт, правила, листы, жанры, атмосферу, сеттинг, дату, дополнительные услуги, пожелания и контакты. «Просто сделайте красиво» пропускает детали. Цена пересчитывается сервером, бронь утверждает мастер. Примерный прайс меняется в настройках. Магазин пока содержит услуги и место для будущих физических товаров, без оплаты/доставки.

## ChatGPT, Codex и модели

Сохранён дополнительный вход через ChatGPT и добавлен **MCP `/mcp`**. Инструменты: `characters_list`, `character_get`, `character_create`, `character_update`, `dice_roll`, `rules_search`, `sessions_list`, `clues_list`. Доступы такие же, как в интерфейсе, с защитой чужих персонажей и закрытых улик. MCP поддерживает `server/discover`, `initialize`, `tools/list`, `tools/call` и stateless JSON-RPC.

Sites создаёт персональный плагин при публикации с capability `mcp`; подключение выполняется через него. Модель выбирается в ChatGPT/Codex, ключ OpenAI для этого не требуется. Использование внешних моделей через отдельный API и локальный MCP stdio-транспорт здесь не настроены. Локальная игра работает без моделей и без аккаунта.

## Android / iOS

```sh
npm run mobile:sync
npm run mobile:android
npm run mobile:ios
```

Проекты `android/` и `ios/` уже созданы, плагины синхронизируются из общей кодовой базы. Для APK/IPA необходимы Android Studio/SDK/JDK и Xcode/signing. В этой среде компиляция установочных пакетов не проверена. Требования: https://capacitorjs.com/docs/getting-started/environment-setup.

При удалённом backend задайте `VITE_API_URL` до сборки. Для автономного телефона выберите локальный режим. Сохранение файлов через browser download и поведение Service Worker в native WebView требуют проверки на реальном устройстве.

Локальные напоминания за час реализованы через Capacitor. Push регистрирует APNs/FCM-токен и использует серверный `PUSH_GATEWAY_URL`, который нужно подключить отдельно; Firebase, iOS Push capability и signing не настроены. После изменения/отмены встречи локальное напоминание пока не синхронизируется автоматически.

## Google, Telegram и ключи

Готовый адаптер: `scripts/google-apps-script.gs`. В Apps Script включить Calendar API, задать Script Properties `SECRET`, `SHEET_ID`, `CALENDAR_ID`, опубликовать Web App от владельца. На сервере указать `INTEGRATION_URL` и `INTEGRATION_SECRET`. Скрипт сохраняет анкеты в Google Таблицы, читает занятость календаря, создаёт событие при подтверждении и отправляет email. Пользовательские строки защищены от формул таблицы.

Telegram мастеру: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` на сервере. Telegram игроку: бот должен получить `/start`, в Script Properties нужен `TELEGRAM_CONTACTS` с соответствием username → chat ID; сейчас это ручная привязка. По телефону связывается мастер. Настройка ключей не выполняет тестовую отправку автоматически.

Без ключей данные сохраняются в приложении, внешние сообщения остаются в очереди. Есть ручной повтор отправки; провайдер может получить повтор после сбоя (at-least-once). Дедупликация календаря — по ID события, таблицы — по eventId. Двусторонней синхронизации календарей и фонового планировщика очереди пока нет.

Секреты: локально `.dev.vars` / `.local/`, на хостинге runtime secrets Sites. Никогда не помещать секреты в `VITE_*`, исходники или GitHub. Имена конфигурации — в `.env.example`.

## Публикация и домен

GitHub: https://github.com/darkPeppa/dnd_neustroy. Репозиторий создан пользователем публичным; локальные данные, секреты и Git credentials в него не входят. CI собирает проект и запускает тесты на Node 24.

Домен **neustroy.ru** привязан со стороны хостинга, но пока ожидает изменения DNS у провайдера Tilda. Доступа к этим настройкам в текущей сессии нет. Точные A/TXT-записи: локальный файл DNS.md (коды подтверждения не публикуются в GitHub). До активации домена используется технический адрес Sites. Своя регистрация работает после снятия внешнего ChatGPT-гейта; защищённые операции требуют сессию приложения или личность ChatGPT.

## Разработка и проверки

```sh
npm run build
npm test
```

Для Cloudflare-совместимой локальной разработки: `npm run db:migrate`, затем `npm run dev`; быстрый фронтенд — `npm run dev:ui`. `LOCAL_DEV=true` применяется только к loopback и никогда не публикуется. Существующий `wrangler.toml` предназначен для локальной разработки, `npm run local` не требует Wrangler или аккаунта Cloudflare.

Проверки используют изолированную D1/R2: аккаунты, сессии, права владельца, независимость персонажей, закрытые файлы, ограничение мест, конкуренция брони, MCP, расчёты редакций и обратная совместимость JSON. Для Miniflare нужны разрешённые локальные порты. Миграции после публикации добавляются новым SQL-файлом; применённые миграции не редактировать.

Юридические тексты и реквизиты владелец добавляет в настройках. Коммерческий платёжный поток пока отсутствует. Официальное описание лицензий: https://www.dndbeyond.com/srd.
