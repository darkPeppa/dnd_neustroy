# Проверки neustroy

Перед серверными тестами выполнить `npm run build`. Тесты запускают Worker на отдельной D1/R2 в Miniflare. Telegram-апдейты синтетические. Они проверяют обработку и ответы без отправки сообщений реальному боту.

| Набор                | Входные данные и ожидаемый результат                                                                                                                                                                                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Доступ и аккаунты    | Регистрация с паролем, вход через cookie и bearer, роль первоначального владельца, отзыв сеанса, запрет доступа к API/MCP чужого листа. Сброс пароля использует токен один раз, делает старый пароль и старые сеансы недействительными.                                                         |
| Telegram и настройки | Повторное использование ссылки и кода отклоняются. Личный чат добавляет заметки в выбранную игру. Группы и скрытые материалы исключены. Отвязка отзываёт Telegram-токен. Администратор сохраняет отдельные настройки, игрок получает 403, ключ не возвращается из API и хранится в шифротексте. |
| Кампания и роли      | Попытка назначить себе роль мастера и сменить редакцию без прав отклоняется. Закрытая родительская папка скрывает файл, циклы и ссылки на другую кампанию не принимаются. Только автор видит личную заметку, GM-секрет не приходит игроку, старые ревизии не перезаписывают новые.              |
| Чаты и журнал        | Личное сообщение читают оба участника, но не мастер и не третий игрок. Личные записи лога изолированы. Общие записи видны группе.                                                                                                                                                               |
| Гости, копии и поиск | Приглашение выдаёт токен наблюдателя, исчерпывается после одного входа и отзывается вместе с активным доступом. Копия исключает заметки другого игрока, восстанавливает вложение и переадресует ссылки. Игрок без права на папку не находит текст вложения.                                     |
| Время и брони        | Общие интервалы объединяют смежные окна и отбрасывают короткие. Одновременные брони и заявки на последнее место не переполняют расписание. ICS сохраняет UTC и переносит длинные строки.                                                                                                        |
| Персонажи и вложения | Проверяются 12 классов, границы уровней, правила двух редакций, слоты и подготовка, преимущество, отдельные лучи, КД, HP, совместимость старых листов и серверный расчёт цен. Посторонний не читает портрет. Поток сверх лимита отклоняется.                                                    |
| Kotlin               | `npm run test:native` проверяет математику листа, броски, ячейки, источники, офлайн-запись и ревизии, расчёт брони, сетевые адреса и cookie. Полная `npm run apk` добавляет Android lint.                                                                                                       |
| Запуск               | `npm run test:local` и `node tests/local-runtime-smoke.mjs --accounts` проверяют настоящий SQLite-сервер с перезапуском. В режиме аккаунтов создаётся мастер, лист переживает перезапуск, а отозванный токен больше не открывает API.                                                           |

Ручная приёмка на телефоне: установить APK, создать офлайн-лист, подключиться к серверу, зарегистрироваться и снова открыть приложение, проверить выход. Настроить своего бота, привязать тестовый профиль, получить код, войти по нему, отозвать привязку. Проверить права на материалы и личные чаты с двумя аккаунтами. Для теста писем, Telegram и моделей нужны реальные ключи соответствующих сервисов.
