# Запуск neustroy на Mac

## Посмотреть в браузере

Если сервер уже запущен, откройте [neustroy на этом Mac](http://127.0.0.1:8787/). Для быстрого знакомства выберите **На этом устройстве · без аккаунта**. Листы и заметки в этом режиме принадлежат браузеру.

Чтобы проверить аккаунты, откройте **Регистрация**. Первый аккаунт, созданный при прямом запуске на этом Mac, станет владельцем сервера. Если уже включён автономный режим, выберите **Настройки → Устройство и доступ → Перейти ко входу в облако**. Это вернёт вас к входу на локальном сервере.

Когда сервер остановлен, в Терминале выполните:

```sh
cd "$HOME/днд приложение/questbook"
node scripts/node-runtime.mjs scripts/local-server.mjs --accounts
```

Терминал оставьте открытым. Остановка — Ctrl+C. Если проект только скачан и ещё не собран, сначала выполните `npm ci` и `npm run build` в Node.js 24. `npm run server` запускает тот же режим с доступом с других устройств вашей Wi-Fi сети.

## Попробовать настольный клиент

Скачайте `neustroy-macos-arm64` или `neustroy-macos-x64` из артефактов [Release builds](https://github.com/darkPeppa/dnd_neustroy/actions/workflows/mobile.yml) или соберите DMG командой `bash mobile/build-desktop.sh :desktopApp:packageDmg` при наличии JDK 21 и Android SDK. Откройте DMG и перенесите **neustroy** в «Программы». Сборка для тестирования без нотариального заверения. DMG, собранный на Apple Silicon, предназначен для Mac с этим процессором.

В приложении выберите **Начать локально** или введите `http://127.0.0.1:8787` и войдите в тот же аккаунт, что и в браузере. Сервер и настольное окно запускаются отдельно. Telegram подключается в настройках владельца по [инструкции](README.md).
