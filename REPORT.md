Сборка и проверки: 33 теста веба и API, 16 тестов Kotlin и Android lint. Проверены установка серверных зависимостей, сборка Docker и ответ сервера из контейнера, запуск из Node 20 с переключением на Node 24, сохранение листов и вход после перезапуска. APK собирается с подписью разработки. iOS требует подписи Apple. Результаты упаковки каждой ОС доступны в GitHub Actions. Проверки с физическим телефоном и реальными токенами Telegram, почты и моделей ещё нужны.

Реализовано частично: мультикласс и повышение уровня представлены отдельным инструментом, без полного пересчёта мультиклассового листа. Синхронизация офлайна с разрешением конфликтов не завершена. Поиск текста PDF и OCR вложений требуют дальнейшей интеграции. Пресеты оформления есть, пользовательские темы не реализованы полностью. Уведомления на телефоне локальные, полный FCM/APNs не подключён. Оплата игровых заказов и доставка физических товаров пока не подключены. Для разовой покупки доступа ведущего нужна конфигурация ЮKassa и проверка в тестовом магазине. Часть дополнительных модулей работает как редактор записей и не автоматизирует все правила.

Приватный Site требует внешнего входа ChatGPT. Независимые аккаунты и опрос Telegram работают через отдельный сервер. Для доступа из интернета серверу нужен HTTPS-адрес. Домен neustroy.ru ждёт доступа к DNS.

## Добавлено в 1.1.0

- Каталог кампаний с поиском по городу, формату и теме. Заявки игрока и наблюдателя, одобрение мастером, временный вход по QR.
- Каталог ведущих, подбор по анкете и описанию, отдельный прайс, услуги и заказы каждого ведущего. Стартовый профиль neustroy наследует ранее заданные цены.
- Право публикации у владельца и аккаунтов с подтверждённой оплатой доступа. Проверка платежа выполняется на сервере через ЮKassa. Подключение реального магазина ещё требуется.
- Базовые помощники без ключа, отключение в профиле и кампании, свой ключ с защищённым сохранением или вход OpenRouter. Проверки OAuth и платежей использовали синтетический провайдер.
- Готовые и личные шаблоны настроек кампании. Генератор геометрического фона по описанию. Фон хранится вместе с настройками игры.
- Workflow Release builds выпускает Android, архив iOS, macOS для Intel и Apple Silicon, переносимый Windows, Linux, веб и Docker. Пакеты одной версии содержат номер коммита и контрольные суммы.
